context
engineering

/ˈkɒn·tekst ˌen·dʒɪˈnɪə·rɪŋ/ noun
Giving AI the right information, at the right time. Not more information: the right information.
REAL EXAMPLE

You ask an agent: "Prepare my weekly report." It needs:

  • ✓ the data: this week's sales file
  • ✓ what matters: your goals and priorities
  • ✓ the format: last week's report as a template
  • ✗ not: old notes, a 2019 budget, the lunch menu
TRY IT TODAYBefore you ask ChatGPT or Claude for anything, paste 3 things: the data, what matters most, and one example of a good result.

harness
engineering

/ˈhɑː·nɪs ˌen·dʒɪˈnɪə·rɪŋ/ noun
The model is the brain. The harness is everything around it that lets it actually do the work.
agent = model + harness
REAL EXAMPLE · A CODING AGENT

Coding agents like Claude Code and Codex are harnesses around a model. The harness lets it:

  • read files in your project
  • run tools: the terminal, the tests
  • track progress with a to-do list
  • know when to stop: tests pass, or ask you first
WHY IT MATTERSSame model, better harness = a much more useful agent. That's why two AI tools built on the same model can feel so different.

THE AI DICTIONARY03 / 03

evals

/iːˈvælz/ noun · short for evaluations
Tests that check, systematically, whether the AI is doing the job properly. Not "it looks good". Proof.
REAL EXAMPLE

Your agent wrote a beautiful weekly report. Run the evals:

✓ PASS totals add up ✓ PASS matches the template ✗ FAIL region "West" missing score: 2 / 3 → fix before you trust it
HOW TO STARTKeep 10–20 past tasks where you know the right answer. Run them again every time you change the prompt, the model or the tools. Track the score.

THE AI DICTIONARY+ MORE TERMS

AI agent

An AI that plans and takes several steps with tools to reach a goal, not just one answer.

"Book a meeting with Priya": checks your calendar, drafts the email, sends the invite.

Tokens

The small chunks of text a model reads and writes. Roughly ¾ of an English word each. Pricing and limits are counted in tokens.

"unbelievable" can be split into a few tokens.

Context window

How much text (in tokens) the model can see at once: its working memory.

In a very long chat, early details can fall out or get ignored.

Tool calling

The model asks to run a tool (search, calculator, an app) and uses the result.

"Weather in Delhi?" → calls a weather service → answers with live data.

RAG retrieval-augmented generation

Look up the right documents first, then answer using them.

An HR bot searches the leave policy before answering "how many sick days do I get?"

MCP model context protocol

An open standard for plugging AI apps into tools and data, like a USB-C port for AI.

Connect your assistant to GitHub or Google Drive once; any MCP app can use it.

Fine-tuning

Extra training on your own examples to change how a model behaves. Try context engineering first: it's cheaper.

Training on 1,000 of your support replies so it writes in your brand voice.

Hallucination

A confident answer that's simply wrong or made up. RAG and evals help catch it.

Citing a research paper that doesn't exist.

Guardrails & prompt injection

Guardrails are checks around what goes in and out. Prompt injection is hidden text that tries to hijack the AI.

A web page hides "ignore your instructions"; a guardrail can flag or block the agent from obeying it.

Human in the loop

A person approves risky steps before the AI acts.

The agent drafts a refund; you click approve.
