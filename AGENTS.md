# Video Lab instructions

## Instagram reel scoring

For Swati's Tech Page (@swatisingh.tech), requests such as “score my script,” “score this reel,” or “score the hook” refer to the GitHub-backed workflow in [Instagram Agent instructions](docs/INSTAGRAM_AGENT_SKILL.md). Load that workflow and its pinned `/ig-reel` instructions before drafting or scoring. Run the pinned `hookscore.py` on the actual spoken opening. For a script or reel scoring request, review the full script using the workflow and report that review separately from the hook score. Clearly identify which results come from the tool and which are editorial. If the required workflow is unavailable, report the specific blocker. An ad hoc score cannot substitute for the GitHub workflow.
